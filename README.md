# متجر إلكتروني خاص

## التشغيل
افتح `index.html` في المتصفح، أو شغّل خادم محلي مثل `python -m http.server 8000`.

## الملفات
- `index.html`: واجهة المتجر
- `css/style.css`: التنسيق
- `js/app.js`: عرض المنتجات، البحث، الأقسام، السلة، وإرسال الطلب التجريبي
- `database/schema.sql`: هيكل قاعدة بيانات Supabase مع سياسات الحماية

## ملاحظات
- المنتجات الحالية تجريبية، والطلبات تحفظ محلياً للعرض فقط؛ لا تُرسل إلى قاعدة بيانات حقيقية بعد.
- قبل استقبال الطلبات الفعلية، يجب ربط واجهة الطلب بدالة خادم آمنة تتحقق من الأسعار والمخزون وتكتب الطلب في Supabase.
- لا تضع مفتاح Supabase service_role في ملفات المتصفح.
